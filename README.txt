NiaH's Game World (DJMAX Respect V 스타일 니아 리듬게임 모드) — 베타 테스트 가이드
================================================================

버전: 1.57.1
필요 앱: Little LUMI 1.4.0 이상 (그보다 낮은 버전에서는 모드가 로드되지 않습니다)


1. 설치 방법
------------
1) Little LUMI를 완전히 종료합니다 (트레이 아이콘까지 전부 종료).
2) 이 zip 안의 "니아의 게임월드" 폴더를 통째로 복사해서
       Little LUMI 설치 폴더\mods\
   안에 붙여넣습니다.
   예) C:\Program Files (x86)\Steam\steamapps\common\Little LUMI\mods\니아의 게임월드\
   (업데이트하는 경우: 기존 mods\ 안의 이 모드 폴더(이전 이름의
    mods\NiaHs_Game_World\, mods\NiaH_RythmGame\, mods\Niah\ 폴더 포함)가
    있다면 통째로 지우고 새로 풀어넣는 것을 권장합니다. 플레이 기록·설정·곡
    라이브러리는 이 mods\ 폴더가 아니라 앱의 plugindata\ 안에 별도로 저장되어
    있어서, mods\ 안의 모드 폴더를 지워도 사라지지 않습니다. 그 위에 그냥
    덮어써도 되지만, 예전 버전의 jar 파일 이름이 바뀐 적이 있어 옛 jar가 같이
    남아있으면 모드가 두 번 로드될 수 있으니 통째로 지우고 새로 넣는 쪽이 더
    안전합니다.)
3) Little LUMI를 실행합니다.
4) 설정 > 모드(Mods) 탭에서 "니아의 게임월드" 모드를 찾아 체크박스를 켜서 동의합니다.
   (코드가 들어있는 모드는 기본적으로 꺼져 있어서, 최초 1회 또는 jar이 바뀔 때마다
    이 동의가 필요합니다.)
5) Little LUMI를 완전히 종료했다가 다시 실행합니다. (동의만으로는 바로 적용되지 않고,
   재시작해야 실제로 로드됩니다.)
6) 니아 캐릭터를 우클릭하거나 트레이 메뉴에서 리듬게임 허브를 열면 준비 완료입니다.

* v1.50.0 이전 버전(모드 이름이 "Niah"였던 버전)을 이미 써보셨다면, 처음 실행할
  때 그때 만든 설정·곡 라이브러리·최고 기록을 자동으로 이 버전으로 옮겨옵니다.
  옛 데이터는 지워지지 않고 그대로 남아있으니 걱정하지 않으셔도 됩니다.
* v1.51.0~1.53.2(모드 폴더 이름이 영문이었던 버전)을 쓰고 계셨다면, 이번 이름
  변경도 표시 이름/폴더 이름만 바뀐 것이라 데이터 이전 과정 없이 그대로 이어집니다.


2. 알려진 제한 사항 (버그 아님)
-------------------------------
- 보이스(대사 음성)가 전혀 들리지 않는 것은 정상입니다.
  원본 게임 성우 음성 파일은 저작권 문제로 이 모드에 포함하지 않았고, 개발자 본인
  PC의 로컬 폴더만 참조하도록 만들어져 있습니다. 다른 PC에서는 조용히 건너뛰도록
  되어 있어 게임 진행 자체에는 지장이 없습니다.

- 유튜브 URL로 곡 추가하기 / 애니메이션 배경 기능은 내부적으로 yt-dlp.exe,
  ffmpeg.exe가 필요한데, 최초로 이 기능을 쓸 때 모드가 알아서 백그라운드에서
  자동으로 받아옵니다 — 따로 다운로드하거나 폴더에 넣어줄 필요가 없습니다.
  (최초 1회만 다운로드 때문에 시간이 조금 걸릴 수 있습니다. 인터넷 환경 때문에
   자동 다운로드가 실패하면, 그때는 아래 경로에 직접 받아서 넣어주시면 됩니다.)
    - 수동 설치가 필요한 경우 다운로드: https://github.com/yt-dlp/yt-dlp/releases
      (yt-dlp.exe), https://www.gyan.dev/ffmpeg/builds/ (ffmpeg.exe, "essentials"
      빌드면 충분)
    - 넣을 위치: Little LUMI 설치 폴더\app\plugindata\niah_rythmgame\tools\
      (폴더가 없으면 새로 만들어서 두 exe 파일을 넣으면 됩니다.)
    - 로컬 wav 파일을 직접 추가해서 플레이하는 것은 이 도구 없이도 바로 됩니다.


3. 기본 조작법
--------------
- 허브(로비) 화면
    ↑ / ↓  : 곡 변경 (목록 끝에서 반대쪽으로 순환)
    ← / →  : 선택한 곡의 난이도 변경 (쉬움/보통/어려움, 순환)
    Enter  : 선택한 곡 재생
    연습모드 / Shift키 노트 / 퍼펙트 오토 버튼 : 각각 켜고 끌 수 있는 토글
      * 퍼펙트 오토를 켜면 모든 노트가 자동으로 완벽 판정되어 채보 감상용으로 쓸 수
        있습니다. 연습모드/퍼펙트 오토로 플레이한 결과는 최고 기록/경험치에는
        반영되지 않습니다.
- 인게임: 설정에서 지정한 4개 레인 키(기본 A, S, ;, ') + 사이드 노트 키로 플레이합니다.
- 곡마다 난이도(쉬움/보통/어려움)를 따로 고를 수 있고, 최고 점수·등급도 난이도별로
  따로 기록됩니다.
- 채보 편집기에서 노트를 직접 그리거나 지울 수 있고, 노트 낙하 속도(템포)도 곡마다
  따로 조절할 수 있습니다.


4. 문제가 있을 때
-----------------
- 모드가 안 보이거나 활성화가 안 될 때: 설정 > 모드 탭에서 체크박스가 켜져 있는지,
  그리고 그 상태로 앱을 완전히 재시작했는지 확인해주세요.
- 새 버전으로 덮어쓴 뒤에는 항상 모드 체크박스를 다시 한번 켜주고(재동의) 완전히
  재시작해야 합니다.
- 그 외 문제나 버그를 발견하시면 어떤 상황에서 발생했는지(곡, 난이도, 어떤 화면
  이었는지)와 함께 알려주세요.
